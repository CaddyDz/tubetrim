# Getting started

## Prerequisites

- Docker with the Compose plugin (`docker compose version`)
- Git

That's all for the recommended setup: Python, ffmpeg, and deno all live inside the image.

## Run the app

```sh
git clone https://github.com/CaddyDz/tubetrim.git
cd tubetrim
docker compose up --build
```

Open <http://localhost:8000>. Interactive API docs (generated by FastAPI) are at <http://localhost:8000/docs>.

Compose starts two services:

| Service | What it is |
|---|---|
| `api` | The FastAPI app, run with `uvicorn --reload` |
| `pot-provider` | [bgutil-ytdlp-pot-provider](https://github.com/Brainicism/bgutil-ytdlp-pot-provider), a sidecar that mints YouTube PO tokens. It is only reachable inside the Compose network. |

### Live reload

`compose.yaml` bind-mounts `app/`, `static/`, and `tests/` into the container, and uvicorn runs with `--reload`. Edit Python files and the server restarts; edit `static/` and just refresh the browser. You only need `--build` again when `Dockerfile` or `requirements*.txt` change.

> The production `CMD` in the `Dockerfile` has no `--reload`; Compose overrides it for development.

## Run the tests

```sh
docker compose run --rm api pytest
```

The tests make no network calls (yt-dlp is replaced with fakes), so they're fast (about 2s) and deterministic.

### Without Docker (tests only)

Requires Python 3.12+ and `ffmpeg`/`ffprobe` on your `PATH`:

```sh
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
pytest -rs
```

Without ffmpeg, the processor and job-flow tests **skip** rather than fail. `-rs` prints the skip reasons so you notice.

Running the full app outside Docker is possible but not recommended: you also need `deno` on your `PATH` and a reachable PO-token provider (set `POT_PROVIDER_URL`). Downloads 403 without both.

## Configuration

| Env var | Default | Purpose |
|---|---|---|
| `DATA_DIR` | `data` (`/srv/data` in the image) | Where per-job working directories go |
| `POT_PROVIDER_URL` | `http://pot-provider:4416` | Base URL of the PO-token sidecar |

## Project layout

```
app/
  main.py         FastAPI app: routes, job runner, startup cleanup
  schemas.py      Pydantic request/response models, JobStatus enum
  jobs.py         Job dataclass + thread-safe in-memory JobRegistry
  urls.py         YouTube URL / video-ID validation and canonicalization
  downloader.py   yt-dlp wrappers: fetch_info, download_audio
  processor.py    ffmpeg wrappers: probe_duration, convert
static/           Vanilla HTML/CSS/JS frontend (no build step)
tests/            pytest suite
docs/             You are here
.github/workflows CI
```
